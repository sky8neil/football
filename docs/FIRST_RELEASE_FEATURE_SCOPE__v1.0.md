## 2. 产品定位和用户

- **产品定位**：足球比赛比分预测与成长排行，免费、纯娱乐；不是投注或交易产品。严禁引入充值、赔率、提现、积分兑换或转移等机制。[来源：MVP v2.0 §1](MVP__v2.0.md)
- **支持六个联赛**：英超、西甲、意甲、德甲、法甲、中超；**联赛赛季与平台等级赛季严格隔离**，不得混算。[来源：MVP v2.0 §1](MVP__v2.0.md)
- **访问模型（游客优先）**：小程序默认直接进入比赛首页（`D-S1-06`），游客无需登录即可浏览六联赛赛程、比赛详情、休赛期状态与公开战绩；预测提交、我的预测、排行榜、群组、个人设置等受登录态及权限边界约束，互动或访问受限页面时再引导登录/起昵称。
