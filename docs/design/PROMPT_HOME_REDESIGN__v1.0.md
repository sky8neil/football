# 任务：为「赛事预言家」微信小程序首页做视觉重设计（换皮，不换骨）

> 说明：如果你能接收附件，我会附上当前定稿首页的 HTML 源文件供参考；附件与本说明冲突时，**一律以本说明为准**。
> 请直接给出完整方案，不要先反问我问题。

## 一、你要做的事

下面是一个**已经定稿并实现完的微信小程序首页**（足球比分预测，中文界面）。请你**在完全保留现有元素、信息结构、功能逻辑和交互行为**的前提下，重新设计它的**配色、风格和视觉语言**——也就是"换皮不换骨"。

产出物：一版可以直接在浏览器打开看的 **HTML 高保真稿**。

## 二、产品背景

- 产品名：赛事预言家 —— 免费足球比分预测小程序（娱乐性质），主打英超，同时有西甲 / 法甲 / 中超
- 平台：微信小程序，**设计宽度 390px**（兼容 375–430px），竖屏，顶部有状态栏安全区，底部是微信原生 TabBar
- 用户：20–40 岁球迷，通勤或看球时快速刷比赛、提交一次比分预测、看成绩
- 现有气质：清爽、浅色、"绿茵场"运动感。这次你想换成什么风格都行，但必须是**为这个场景服务**的，不是随便套一个流行风格

## 三、硬约束（违反即作废）

1. **元素一个都不能增删**，分区上下顺序不能变（完整清单见第四节）
2. **中文文案一字不改**（包括"用户ID"这种占位文字、按钮文字、提示文字全部原样保留）
3. **交互状态机与命名不变**：卡片展开状态只有 `collapsed / editing / submitting / submitted_locked` 四种；业务状态 `open / lock / live / done` 各自独立，不互相推导
4. **交互行为不变**：
   - 同一时间最多一张卡片处于展开状态；点另一张的"去预测"要先收回旧的再展开新的
   - 提交成功后停在"已提交锁定"状态，**不自动收回**，点页面任意位置才收回
   - 点击展开区内部（加减分、提交按钮）不触发收回
   - 切换联赛 / 日期时：先收回展开卡 → 内容淡出 → 重绘 → 淡入
   - 点击加减分步进器：比分不为负，上限 20，立即更新比分和"主胜/平局/客胜"判定
   - 收回后重新展开，草稿比分归零（0:0），不残留上次的比分
5. **动画时长不变**：卡片展开/收回 320ms、提交成功后收缩 900ms、联赛/日期切换（淡出 180ms + 淡入 240ms）、展开后自动滚动 900ms。缓动曲线可以微调，但要在说明里讲清楚为什么
6. **数据语义不变**：比分缺失时显示"待结算 / 暂无比分"，**禁止用 0 代替**；命中、未命中必须一眼可分
7. **只做单一亮色主题**，不要输出暗色模式，也不要做主题切换
8. 不新增页面、不新增功能、不改布局骨架

## 四、现有首页结构与元素清单（全部必须保留）

从上到下：

1. **顶部品牌区**：一个圆形标志（现在是个装饰圆环）+ 两行文字（上行"用户ID"，下行"今天看哪场？"）
2. **联赛托盘**：一个半透明胶囊托盘，横向滚动，4 个联赛（英超 / 西甲 / 法甲 / 中超）。每个联赛 = 一个圆形 Logo + 联赛名；选中态有强调标记
3. **日期条**：横向滚动 5 个日期（今天17 / 明天18 / 周三19 / 周四20 / 周五21），每个 = 星期文案 + 日期数字；选中态是白底高亮。日期条右侧有一个**日历按钮**（当前是占位，点了弹提示）
4. **统计提示行**：左侧"今日可预测 6 · 已预测 3"，右侧"最近成绩 +12"
5. **比赛列表**（可滚动区域）：每张比赛卡片包含——
   - 卡片左侧有一条**竖向状态色条**（可预测 / 已提交 / 进行中 / 已结束 四种颜色）
   - **顶行**：比赛时间 + 联赛·轮次信息 ｜ 右侧**状态徽章**（未开赛 / 已提交 / 进行中 / 完场 / 延期 / 取消 / 腰斩）
   - **队阵行**：主队（队徽 + 中文队名 + "主队"） ｜ 中间**比分方块** ｜ 客队（队徽 + 中文队名 + "客队"）
     - 比分方块：未开赛显示"VS"，进行中/完场显示比分；副文字分别是"已锁定 / LIVE / FT / 待结算"；进行中和完场时方块是深色
   - **底行**：左侧预测文字（"我的预测 2 : 1" 或"未开赛"） ｜ 右侧"去预测 →"按钮，不可预测时换成状态 chip
   - **状态 chip 文案**：`+3 赛果命中` / `+12 精确命中` / `+0 未命中` / `已锁定 · 不可修改` / `预测已关闭` / `需登录后预测` / `账号已注销` / `开球未确认` / `非可预测赛程`
   - **可展开的预测区**（点"去预测"展开）：两队各自的 −/＋ 步进器改比分、中间冒号分隔、"即时判定 主胜/平局/客胜"、"赛果命中 +3 · 精确比分 +12"提示、"提交预测"按钮 + "提交后无法修改"小字、提交失败时的错误提示、提交中的按钮 loading（文案"提交中…"）、提交成功反馈"✓ 预测已提交"
6. **列表底部**："更多"按钮（加载下一页）
7. **三种状态页**：加载中（现在只有一行字）、空状态（"这一天暂无比赛"+"下拉看看别的日期"）、错误状态（错误文案 + 重试按钮）
8. **底部 TabBar**：4 个 Tab（比赛 / 我的预测 / 排行榜 / 我的），小程序里是原生组件，现在**只有文字没有图标**（图标我们后面另做，你在 HTML 稿里如实画出来即可）

## 五、现状视觉 token（这只是起点，你可以整套换掉）

- 主色：绿 `#7ed56f`（按下 `#2f8a3a`、柔和底 `#e8f8df`）
- 文本：主 `#163024` / 次 `#5b7166` / 弱 `#86a092`
- 页面背景：三层配方（两个白色 + 绿色的径向光晕 + 垂直渐变 `#f4fbf1 → #eef8ef → #f3faf2`）
- 卡片：纯白底 + 1px 边框 `#dcead9` + 绿色调阴影 `rgba(63,138,72,.10)`
- 语义色：已提交 `#3aa37a` ｜ 进行中 `#f08a3c` ｜ 结束/锁定 `#718096` ｜ 错误 `#c05621`
- 圆角：卡片 16px、按钮/日期块 10–14px、胶囊全圆
- 字体：系统中文字体栈（PingFang SC / 微软雅黑）+ 数字用几何无衬线
- 动效曲线：`cubic-bezier(0.2, 0.8, 0.2, 1)`

## 六、这次可以改的部分（重设计范围）

- 整套配色（绿色系可以完全换掉）、明暗关系、背景质感、光晕/纹理
- 卡片形态、圆角、描边、阴影与层次语言、分隔方式
- 字体气质（只能用系统字体，不能联网加载字体）、字号与字重层级
- 状态色方案（前提：四种状态一眼可分、对色盲友好、文本对比度满足 WCAG AA）
- 图标、徽章、小装饰的风格（**用内联 SVG 或纯 CSS 画，不要用 emoji**）
- 动效的缓动与视觉表现（**时长不变**）

## 七、工程约束（重要）

- 最终要移植到**微信小程序 WXSS**：请只用 flex / grid / CSS 变量 / transition / animation / 渐变 这些小程序支持的写法；不要用远程字体、CDN、JS 框架、SVG 滤镜、重型特性
- 布局尺寸请用 **px**（我们后面按 1px = 2rpx 换算）
- 队徽和联赛 Logo 是**真实彩色 PNG 素材**（我们后面会贴进去），HTML 稿里请用简单的圆形色块占位即可；不要让方案"必须配单色 Logo 才好看"
- 不要出现英文占位文案，中文必须正常显示
