## 业务口径

- 参考 `MVP__v2.0.md`、`UI_DESIGN_SYSTEM.md` 和当前 `design-tokens.wxss`。Token 在浏览器中按 `1rpx = 0.5px` 换算，不修改正式 Token。
- 原版 `.ring` 的 SVG、136px 尺寸、旋转、4px 描边、96/4 虚线、76px 中央主队队徽及其 data URI 均保留。仅更新无障碍说明，避免沿用旧原型错误的「整体升级进度」。
- 圆环 96% = 生涯积分门槛 `366 / 380` 的约整数百分比，不是准确率，也不意味着即时升级。Lv.4 坐稳主力 → Lv.5 球队核心；表现和积分需同时达线，每周一北京时间 10:00 评估。
- 所有数据、赛事、评估状态与名次均为示例，不是真实用户或赛果。生涯 `150` 场、`366` 分、`12` 次精确命中，另 `74` 次仅胜平负命中；窗口同为 150 场，实力榜预言指数 `(366+68)/(150+40)` 向下保留两位为 `2.28`。本赛季 `80` 场、`153` 分、`3` 次精确命中，另 `39` 次仅胜平负命中，示例赛季等级 Lv.3。示例本周 8 场、24 分、1 次精确命中，另 4 次仅胜平负命中。
- 不显示对外准确率、不设月榜、不展示超过 20 的绝对名次。等级赛季与联赛赛季独立，每年 7 月 1 日切换。
- 群名遵守「群主昵称的预言群」，邀请码 8 位，最多加入 20 群 / 创建 5 群 / 每群 500 人。不虚构微信好友关系链、群聊天、额外勋章或签到任务。
- 根据规范第 18.2 节，30 / 100 / 200 解锁仅保留后端行为，前端不呈现装扮入口、清单或进度，不自行补全 SPEC_GAP 资源。
