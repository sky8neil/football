# v0.3-cc · 墨青 + 一抹金 + 范围并入概览卡

基于 v0.1，只新增 `theme-cc.css`、`rank-filter-cc.js`，v0.1 的页面与 `ui-consistency.css` 未改。两部分互相独立，可单独拿走。

## 1. 深色块：深蓝 → 墨青（`theme-cc.css`）
- 深色块 `#174340 → #0a2828`，偏青，与品牌绿、"已提交"青色同属冷绿一侧，和正绿区分更明显。
- 暖金 `#f3cf6b` 每张深色卡只点一处"最关键的数字"：排行榜 = 我的排名；我的页 = 当前等级节点。其余数字为白色。
- 影响：首页进行中/已结束比分块、排行榜概览卡、我的页升级进度卡。

## 2. 排行榜筛选：范围并入概览卡（`rank-filter-cc.js`）
- 「全站 / 我的群」分段开关移入深色概览卡顶部——它控制的就是这张卡和下面的榜单；选群下拉也在卡内。
- 页面常驻的筛选只剩「本周/赛季/实力/生涯」tabs。
- 代价：范围开关随页面滚走（不吸顶）；卡内多一个控件，卡片略高。
