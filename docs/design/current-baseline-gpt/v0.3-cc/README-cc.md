# v0.3-cc · 状态图册

基于 `v0.2.2-cc`（深松绿 + 页头范围胶囊）和 `docs/UI_DESIGN_SYSTEM.md`，把开发文档 §7、§8、§10 里尚无设计的页面状态画成**完整页面**。
注意：本目录原有的「墨青 + 金」版本已被覆盖（按要求）。

## 怎么看
- 打开 `index.html`：左侧下拉框选状态，右侧是 390×844 的完整页面；`← →` 键可切上一个 / 下一个。
- 每个页面也可单独打开：`rankings-states.html?state=R01`、`my-states.html?state=M02`、`predictions-states.html?state=P01`、`group-states.html?state=G01`。
- `overview.html` 是 v0.2.2-cc 原来的三页并排对照（保留，未改动）。

## 文件
- `rank-states-cc.js`：排行榜状态切换（数据裁剪、空榜、少人、游客占位、周 / 赛季 / 范围弹层）。
- `my-states-cc.js`：「我的」页回顾卡与无群空状态。
- `states-cc.css`：新增组件样式，取值来自 UI_DESIGN_SYSTEM.md（玻璃卡、品牌绿、状态色、字号与圆角档位）。
- `predictions-states.html`、`group-states.html`：新页面，自包含。
- 其余文件沿用 v0.2.2-cc（`theme-cc.css`、`ui-consistency.css`、`rank-filter-cc.js`、`rank-activity-cc.js`、首页等）。

## 说明与限制
- 所有数据为示例；赛季回顾卡、往期赛季使用 2026/27 → 2027/28 的假设时间线，与常态页的 2026 年周数据分属不同场景。
- 游客占位是静态灰色条纹，不含任何用户名、头像、分数。
- 「最近预测」「群」页面是新增页面，现有设计里没有对应稿，仅按现有玻璃卡与按钮样式搭建，需要你确认。
- `previews/` 里是旧截图（来自 v0.2.2-cc 及更早版本），**本版没有生成新截图**。
