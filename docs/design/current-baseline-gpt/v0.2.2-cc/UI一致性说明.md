# 赛事预言家 v0.1 UI 一致性修订

基于父目录的冻结稿修订，保留首页、排行榜两种场次状态、我的 V3-08 的功能和数据结构。此目录是独立设计版本，未修改父目录基准或小程序业务代码。

## 综合判断

三个页面本来已有相同的球场背景、绿系品牌色和玻璃卡片，割裂感主要来自共用组件的规格不一致，而非页面内容布局不同。因此保留比赛列表、排名信息、个人成长的各自结构，集中调整字体、背景、颜色用途、图标和文案。

| 项目 | 原稿差异 | v0.1 统一结果 |
| --- | --- | --- |
| 页头 | 首页是 Sky + 品牌图标，另两页是徐sir + 头像；首页缺少状态栏 | 同一示例用户、34px 用户头像、相同状态栏、14px 问候与 11px 副文案 |
| 背景 | 首页与另两页的蒙层、固定方式不同 | 共用本地球场图片、同一遮盖和定位，滚动时背景保持稳定 |
| 布局 | 首页桌面版 390px / 固定 844px，另两页 375px；页边距 14/16px | 三页最大宽度 390px、共同的 16px 页边距，随视口收缩 |
| 文字 | 辅助信息散落在 8、9、10、11px，部分标题过大 | 模块标题 15px，正文/姓名 13px，说明 11px，标签 10px；排行榜页标题 20px，数字按信息角色分级 |
| 字体 | 首页数字依赖外部 Outfit，其他页有系统回退 | 所有页面采用同一系统字体与等宽数字特性，离线打开也保持一致 |
| 配色 | 首页选中导航偏亮，另两页为深绿；次级文字深浅不一 | 主文字 #163024、说明 #42564a、弱文字 #52665b、选中 #2f8a3a、正向数据 #1a5c26 |
| 色彩语义 | 深色信息块和命中状态未完全呼应 | 绿用于选中与正向数据，青用于已提交/胜平负命中，橙用于比赛进行中，深蓝用于比分和个人关键表现 |
| 卡片 | 浅色卡片 16px，深色卡片 8px，透明度与阴影不同 | 主要卡片统一 16px 圆角、玻璃面和轻阴影；排行榜概览与升级进度共用深色处理 |
| 图标 | 首页导航为公文包，另两页为球场；描边、大小不同 | 三页共用球场/排名/用户图形，22px 导航图标、20px 工具图标、14px 箭头，常规描边 1.7px |
| 导航 | 高度 58/65px，首页随正文滚动，部分按钮仅弹提示 | 三页 64px 固定底栏、安全区适配、10px 标签，并在本版本内真实互相跳转 |
| 文案 | “赛果命中 / 胜平负命中”“预言指数 / 预测评分”并存，中英排名标签混用 | 统一为“胜平负命中”“精确命中”“预测评分”，领奖台统一“第 N 名” |
| 说明可读性 | 场次、等级、规则信息较小 | 规则保留完整内容；积分圆环仍仅代表积分门槛进度，表现与积分同时达线、周一评估等含义保留 |
| 资源 | 首页复制后相对路径缺失，联赛图标和球队队徽无法正常显示 | 随版本收录本地图片和徽标，修复首页资源显示 |

## 页面入口

- `index.html`：三个页面并排对照，可切换排行榜的 150 场 / 38 场状态。
- `赛事预言家首页-高保真-v8.6-球场背景玻璃版.html`：比赛页。
- `rankings-v1.3-over50.html`：达到实力榜 50 场门槛。
- `rankings-v1.3-under50.html`：未达到门槛，保留原稿不展示实力榜的行为。
- `my-growth-v3-8.html`：我的 / 成长档案。
- `ui-consistency.css`：四份页面共用的视觉规格，调整同级元素只需修改此处。

页面可直接本地打开，无需服务端。排行榜“赛季榜”沿用原稿的设计扩展，非已确认上线功能；移除了页面内的接口和验收说明，相关限制记录在此。头像编辑、群管理、预测提交仍是原有本地演示，不请求真实服务。

## 验证

检查手机和桌面视口的横向溢出、头像与徽标加载、同级文字/导航规格、页面互跳；复核预测展开提交、排行榜切换与规则弹窗、我的统计范围与个人资料弹窗。最终结果见 `verification.json`，390px 手机首屏和桌面对照截图见 `previews/`。
