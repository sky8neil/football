# v0.2-cc · 深松绿 + 范围胶囊

基于 v0.1，只新增 `theme-cc.css`、`rank-filter-cc.js`，v0.1 的页面与 `ui-consistency.css` 未改。两部分互相独立，可单独拿走。

## 1. 深色块：深蓝 → 深松绿（`theme-cc.css`）
- 深色块 `#1f4d36 → #0e2d20`，右上角一抹青柠光晕；与品牌绿同色相，只靠亮度拉开层次。
- 深色块里的重点数字用青柠 `#b9f08f`；亮绿渐变（「去预测」）仍是全产品唯一的实心亮绿。
- 影响：首页进行中/已结束比分块、排行榜概览卡、我的页升级进度卡。

## 2. 排行榜筛选：两行 → 一行（`rank-filter-cc.js`）
- 「全站 / 我的群」收进页头的胶囊（显示当前范围，如「全站 ▾」「老张的预言群 ▾」），点开底部弹层选择；群榜的"当前群"下拉并入同一弹层，不再单占一张卡。
- 页面常驻的筛选只剩「本周/赛季/实力/生涯」tabs；周选择器仍只在本周榜出现。
- 代价：切群多一次点击；范围入口不如 tabs 显眼（由概览卡标题里的范围名补偿）。
