# v0.2.1-cc · 深松绿 + 范围胶囊 + 赛季榜资格

在 v0.2-cc 基础上，按更新后的 `docs/MVP__v2.0.md`（第 19.9 节）加入赛季榜资格逻辑。

## 赛季榜规则（已写入规范）
- 赛季榜 = 当前**等级赛季**（7 月 1 日起算）累计积分榜，`board=season`。
- **可见资格**：参与过 ≥2 个等级赛季（含当前，有效预测 ≥1 场才算参与）。首个赛季的用户看不到赛季榜 tab——此时它与生涯榜相同。
- **榜单收录所有人**（本赛季有效预测 ≥1 场）：资格只决定入口是否展示，不过滤榜单本身。
- API：所有榜的响应带 `season_board_visible`；资格不足者请求赛季榜，列表照常返回，`me.status = not_eligible`。

## 页面里怎么切换
- `index.html` 排行榜列的第二个下拉框：「≥2 赛季 · 有赛季榜」/「首个赛季 · 无赛季榜」。
- 单独打开排行榜页时，用 URL 参数：`rankings-v1.3-over50.html?seasons=1`（首个赛季）或 `?seasons=2`（默认）。
- 首个赛季时：tab 里没有「赛季榜」；若停留在赛季榜会自动回到本周榜。
- 与「150 场 / 38 场」（实力榜门槛）独立组合，共 4 种排行榜状态。
