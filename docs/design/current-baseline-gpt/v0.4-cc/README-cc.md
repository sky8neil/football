# v0.4-cc · 三页对照 + 状态预览（合并 v0.2.2-cc 与 v0.3-cc）

- 以 **v0.2.2-cc 的三页并排对照**为首页（`index.html`），默认打开的是 **20 人以上的常态**页面（排行榜 R06、我的 M01）。
- 把 v0.3-cc 的全部状态页面并入：排行榜和「我的」两列各有一个下拉框，可切换成不同状态的**完整页面**。
- **样式不改**：`theme-cc.css`、`ui-consistency.css`、`states-cc.css`、各页面样式与 v0.3-cc 完全一致；只调整了首页导航的跳转目标，让它指向状态页。

## 怎么看
- `index.html`：三页对照。
  - 排行榜下拉框：R01–R18 的状态，另保留 v0.2.2-cc 的「38 场 · 实力榜未达门槛」原页面（R19）。
  - 「我的」下拉框：M01–M03（我的页）、P01–P04（最近预测）、G01–G03（预言群）。
- `gallery.html`：单页大图版状态图册（同一份状态清单，左边有说明和要点，支持 ← → 键切换）。
- `overview.html`：v0.2.2-cc 原来的三页对照，未改动。
- 状态清单在 `states-data.js`，两个页面共用；新增状态时只改这一个文件和对应页面脚本。

## 状态一览
见 `gallery.html` 左侧说明，或 v0.3-cc 的 README。排行榜 R01–R18、我的 M01–M03、最近预测 P01–P04、预言群 G01–G03。

## 限制
- 示例数据；赛季回顾与往期赛季使用 2026/27 → 2027/28 的假设时间线。
- 最近预测页、预言群页是新增页面，现有设计里没有对应稿。
- 开发这台机器当时没有浏览器，本版**未做浏览器实测**，请打开看一遍再确认。
