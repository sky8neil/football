# v0.41-cc · 比赛详情页 + 大家怎么选（在 v0.4-cc 上新增）

v0.4-cc 的全部内容原样保留；新增 **比赛详情页** 和 **「大家怎么选」**（只做截止后档）。样式沿用既有玻璃卡、品牌绿、状态色，不改任何已有样式。

## 新增文件
- `match-detail-states.html`：比赛详情页，`?state=D01…D12` 切换状态。
- `detail-cc.css`：详情页与「大家怎么选」的样式（只作用于新页面）。
- `home-crowd-cc.js`：首页比赛卡的次入口。进行中、完场的卡片出现「大家怎么选 ›」，进入详情页；未截止的卡片不出现。
- `index.html`：「比赛」一列新增下拉框，可在首页和 12 个详情页状态之间切换；其余沿用 v0.4-cc。
- `states-data.js` 新增「比赛详情」分组，`gallery.html` 自动出现。

## 「大家怎么选」设计要点（对应已定的后端规则）
- **只做截止后档**：比赛截止前只显示一行锁定提示；截止后才出现分布。赛前档记在规范第 48.1 节的「计划完成」里。
- **只展示主胜 / 平局 / 客胜三项**，不做热门比分。
- **百分比按 5% 取整**；**单场至少 20 人预测**才显示，否则「参与人数不足」；**游客看不到**，登录后可看。
- 颜色不用红绿对冲，主胜品牌绿、平局灰、客胜深青；页脚注明「仅展示用户选择分布，不构成任何推荐」。
- 赛后对照：高亮「实际结果」，并说明你和多少人选择一致；没预测的用户看到「多少人选对了结果」。

## 放置位置
- 主入口：比赛详情页（真实小程序点首页比赛卡就进入详情页，该页目前只是白底占位，设计稿里原先没有）。
- 次入口：首页比赛卡上的「大家怎么选 ›」小链接，只在进行中和完场的卡片出现。

## 限制
- 示例数据；分布固定为 45% / 25% / 30%。
- 详情页的步进器、提交按钮只做静态展示，不响应点击。
- 本机没有浏览器，**未做浏览器实测**，请打开看一遍再确认。
