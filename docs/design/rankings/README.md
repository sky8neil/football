## 业务边界

- **规范冲突已显式处理**：现有 `MVP__v2.0.md` §19 的榜单枚举只有 `week / career / strength`，§1.3 排除整赛季独立排行榜。用户要求的「赛季榜」以 §16 当前等级赛季积分作为**设计扩展**展示，页签、摘要和规则弹层均注明非现有 MVP 接口，不能直接发送 `board=season`。同时保留规范要求的生涯榜。
- 本周按北京时间自然周（周一 00:00 至下周一 00:00）归属，至少 1 场已结算有效预测入榜。没有月榜。
- 实力榜指数 `(B + 68) / (V + 40)`，B 为窗口积分，V 为窗口有效场次；最近 730 天内最多 300 场，至少 50 场才入榜，显示值向下保留两位。排序使用未截断的比值；指数不等于准确率。
- 仅提供 Top 20，每次显示 10 条。我的名次 ≤20 展示绝对名次；其余展示 `clamp(ceil(100 × r / N), 1, 99)` 的前百分比，N 为当前范围入榜人数。
- 全站与群内分别计算名次。群是平台自建预言群，不是微信好友榜。未结算预测不参与榜单。
- 同分优先级在规则弹层完整说明；不公开他人未过截止时间的预测内容。
- 我的示例与成长档案保持一致：本周 24 分 / 8 场 / 精确命中 1 次；赛季 153 分 / 80 场 / 精确命中 3 次；生涯 366 分 / 150 场 / 精确命中 12 次；实力指数 2.28、窗口 150 场。
- 演示日期为 2026-09-30。本周为 09.28–10.04；历史周为 09.21–09.27，仅演示周期切换布局，复用示例行，不假装请求真实历史数据。
- 等级赛季为平台统一口径，每年 7 月 1 日切换，不与各联赛赛季混用。赛季榜排序是本次设计探索，不代表已确认接口方案。

## 可体验交互

- 本周 / 赛季扩展 / 实力 / 生涯四个页签，全站 / 我的预言群范围，两个群之间切换。
- 本周 / 上周周期切换，展开第 11–20 名，点击行或领奖台查看公开成长档案。
- 固定底部「我的名次」同步显示当前范围的名次、积分或指数、有效预测场次、精确命中次数。
- 「设计验收」选择器切换已入榜 / 未上榜；实力榜另可体验窗口 38 场、还差 12 场的门槛提示。
