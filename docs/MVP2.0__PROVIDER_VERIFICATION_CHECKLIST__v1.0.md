# MVP 2.0 数据源验证清单 v1.0

> 用途：交给另一个 AI 或开发者，对 5 个数据源的文档和真实响应做一轮核对，结果回填给开发（见 `docs/MVP2.0__SEASON_BOARD_DEV_PLAN__v1.0.md` 第 18、20 节）。
> 日期：2026-10-12
> 状态：待验证。下列问题都是开发过程中**根据文档摘要产生的疑问**，不是已确认的结论。

## 使用说明

1. 每个问题请回答三选一：**已确认**、**与我的理解不符**、**文档里没写**。
2. 回答时附上依据：文档原话，或一次真实调用的响应（**必须去掉 key**）。
3. 做真实调用时注意额度，只发验证所需的最少请求，不要循环测试：
   - football-data：每个 key 10 次/分钟
   - 5DollarFootballAPI：60 次/小时，每分钟不超过 20 次
   - OpenFootAPI：5000 次/月
   - BSD Sports API：7500 次/天
   - sportapi.ai：用户称 2000 次/天（待确认）
4. **不要把任何 key 写进回答、日志或截图。**
5. 回答格式建议：`编号 | 结论 | 依据（原话或响应片段） | 备注`。
